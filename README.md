# pqc-research

Research notes from [Applied Post-Quantum Cryptography](https://appliedpqc.io/) —
standards, chains, protocols, and the code that implements them.

Companion to the book at [`AppliedPQC/AppliedPQC`](https://github.com/AppliedPQC/AppliedPQC)
and the resource list at [`AppliedPQC/awesome-pqc`](https://github.com/AppliedPQC/awesome-pqc).

## Method

Claims come from **primary artifacts** — specification text, changelogs, issue
trackers, repository trees, and the design documents of the schemes themselves —
not from secondary coverage. Each report records when it was checked and what it
could not verify.

## Status

Dated snapshots, not maintained documents. Standards, repositories and roadmaps
move quickly; check the date at the top of each report.
